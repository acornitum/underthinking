# About

[underthink.ing](https://underthink.ing) is a site for browsing debate motions! as well as finding recorded rounds and drilling.

this site is entirely open source. the github repo with all the code is here: [https://github.com/acornitum/underthinking](https://github.com/acornitum/underthinking). you are encouraged to clone the repo - when run locally, there are notetaking features you'll be able to access.

features you might not know about:
- click on a motion to copy it to clipboard! infoslide included.
- after expanding a motion into a new tab, you can edit it (edits are not saved)
- change the color theme of the site via the icons on the bottom left
- sort recorded rounds by newest tournament / recently uploaded / most watched
- motion genre filtering also works on random motion / recorded rounds / drills pages!
- add markers to the timer for drills! hover over timer preview (or timer) and click to do so
